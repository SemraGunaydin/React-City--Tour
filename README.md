# City Tour Project
This project is a movie site interface built using HTML5, CSS, JavaScript,React, and APIs. It allows users to search, list, and filter tour info based on their content. The design is fully responsive, ensuring seamless accessibility across desktop devices.

# 🚀 Features
- City Tour listing: Browse a collection of tour with detailed information.
- Responsive Design: Optimized for all screen sizes.
  
# 🛠️ Technologies Used
-HTML5 -CSS -JavaScript -API Integration -Node Js -React
